# C++ Project

First-year university coursework for learning **object-oriented programming** in C++.

## About this repository

This repo holds your C++ OOP work: classes, inheritance, polymorphism, and related exercises. Add your own source files and build setup when your module tells you to.

## Suggested layout (when you start coding)

You can organize your work like this (optional):

- `src/` — `.cpp` implementation files  
- `include/` — headers (`.h` / `.hpp`) if you split interface from implementation  
- `docs/` — notes or assignment briefs (if allowed by your course)

## Build tools

Common choices: **g++/clang** on the command line, **CMake**, or your IDE’s build (e.g. CLion, VS Code with a compiler). Your course will usually specify one.
